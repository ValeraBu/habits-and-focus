Обнови экран «Фокус» (`focus-timer`) по обновлённому макету `design-reference/focus-timer.html` и `design-reference/screenshots/focus-timer.png` — сверяйся с ними по стилям, отступам и структуре.

Нужно реализовать четыре вещи:

## 1. Пикер длительности сессии

Над таймером добавь ряд пилюль с длительностью: для режима «Фокус» — 15 / 25 / 45 / 60 мин, для режима «Перерыв» — 5 / 10 / 15 / 20 мин. Активная пилюля — заливка `var(--coral)` для фокуса и `var(--sage)`/`var(--sage-dark)` для перерыва (белый текст), неактивные — `var(--card)` с бордером `var(--border)`.

Выбор длительности:
- обновляет `durationMinutes` в `timer.service.ts` и сразу пересчитывает круг таймера (dasharray/dashoffset и текст времени), если таймер не запущен;
- если таймер уже идёт — по клику на другую длительность либо игнорируем выбор, либо (лучше) показываем лёгкое дизейбл-состояние пилюль на время активной сессии, чтобы не сбивать текущий отсчёт. Выбери сам, как удобнее, но не давай менять длительность запущенного таймера незаметно для пользователя.
- при переключении Фокус/Перерыв показывается соответствующий набор пилюль с активной по умолчанию длительностью (25 мин для фокуса, 5 мин для перерыва — стандартный Pomodoro).

## 2. Кнопки Старт / Сброс

Замени текущие иконки-кружки на пилюли с текстом, как в макете:
- «Сброс» — вторичная кнопка: `var(--card)` фон, бордер `var(--border)`, иконка reset слева, текст `var(--text-soft)`.
- «Старт» — основная кнопка: заливка `var(--coral)`, белый текст, иконка play слева, `box-shadow: var(--shadow)`.
- Когда таймер запущен, «Старт» превращается в «Пауза» (иконка меняется на паузу, тот же стиль), логика уже должна быть в `timer.service.ts` — просто подключи новый вид кнопки к существующему состоянию `isRunning`.

## 3. Стилизованный список «Привязать к привычке»

Замени нативный `<select>` на кастомный listbox-компонент (если такого ещё нет в `shared/components/` — создай, например `dropdown-select`):
- Триггер — пилюля как в макете: иконка привычки слева, название, шеврон справа (поворачивается на 180° при открытии).
- Открытая панель — `position: absolute`, `background: var(--card)`, `border-radius: 16px`, `box-shadow: var(--shadow)`, список опций с `border-radius: 11px` на каждом пункте; выбранный пункт — `background: var(--coral-soft)`, `color: var(--coral-dark)`, галочка справа.
- Закрытие по клику вне компонента и по Esc, доступность — управление стрелками/Enter приветствуется, но не обязательно для pet-проекта.
- Данные — список активных привычек из `habit.service.ts` + опция «Без привычки» первым пунктом.

## 4. Уведомление о завершении сессии (звук + визуал)

Визуальное уведомление — тост, как в макете: карточка `var(--card)` с бордером `var(--sage-soft)`, `box-shadow: var(--shadow)`, круглая иконка-галочка на `var(--sage-soft)` фоне слева, заголовок «Сессия завершена!» + подзаголовок с длительностью, крестик-закрытие справа. Появляется по центру сверху над таймером с лёгкой анимацией (fade + slide down, `prefers-reduced-motion` — без анимации), автоматически скрывается через 5–6 секунд или по клику на крестик. Текст подзаголовка зависит от типа сессии: для фокуса — «N минут в фокусе — отличная работа», для перерыва — что-то вроде «Перерыв окончен, пора вернуться к делу».

Звуковое уведомление — добавь `sound.service.ts` в `features/focus-timer/services/` (уже упомянут в `.cursor/rules/project.mdc`):
- Простой сервис с методом `play(type: 'complete' | 'tick')` (пока нужен только `complete`), проигрывающий короткий мягкий звук через `HTMLAudioElement` или Web Audio API.
- Файл звука — любой короткий (0.5–1.5 сек) мягкий сигнал (колокольчик/чайм), положи в `public/sounds/` или `src/assets/sounds/`; если готового файла нет — сгенерируй простой тон через Web Audio API (`OscillatorNode`), чтобы не тащить лишний бинарник в pet-проект.
- Вызывается из `timer.service.ts` (или из компонента, который слушает завершение сессии) одновременно с показом тоста.
- Добавь в `core`/`shared` простой тумблер «Звук вкл/выкл» — можно маленькой иконкой-колокольчиком в углу экрана «Фокус», состояние храни в `localStorage` через `StorageService`, чтобы не переигрывать звук тем, кто в наушниках у коллег.
