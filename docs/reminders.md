Добавь напоминания о невыполненных привычках — только через браузерные уведомления (Notification API), сверяйся с макетом `design-reference/habit-tracker.html` (попап «Напоминания», открывается по клику на пункт внизу сайдбара) и с обновлённым `.cursor/rules/project.mdc` (раздел «Напоминания о невыполненных привычках»).

## Что нужно сделать

1. **Пункт в сайдбаре.** Добавь внизу сайдбара (после списка навигации, прижат к низу через `margin-top: auto`) пункт «Напоминания» с иконкой колокольчика — по клику открывает попап рядом (справа от сайдбара, как во всех уже реализованных выпадающих панелях в проекте). Закрытие — по крестику, клику вне попапа и Esc.

2. **`notification.service.ts`** в `core/services/`:
   - Сигналы/поля состояния: `reminderEnabled` (boolean), `reminderTime` (строка `"HH:mm"`), оба persist в `localStorage` через `StorageService`.
   - `permissionStatus` — читает `Notification.permission` (`'default' | 'granted' | 'denied'`), реактивно обновляется после `requestPermission()`.
   - Метод `requestPermission()` — вызывает `Notification.requestPermission()`, обновляет `permissionStatus`.
   - При инициализации сервиса (и когда `reminderEnabled` включён) — `setInterval` раз в минуту: сравнивает текущее `HH:mm` с `reminderTime`; если совпало, `permissionStatus === 'granted'` и среди привычек на сегодня есть незавершённые (бери данные из `habit.service.ts`), вызывает `new Notification('Habit & Focus Hub', { body: 'Не выполнено N из M привычек сегодня' })`. Не показывай повторно в течение той же минуты/дня после первого срабатывания — запомни последнюю дату показа (например, в том же localStorage-ключе), чтобы не дублировать уведомление, если таймер сработает несколько раз в одну минуту.
   - Не подписывайся на `setInterval`, если `reminderEnabled === false` — выключай интервал при выключении тумблера.

3. **UI попапа** (компонент можно положить в `shared/components/reminder-settings/` или прямо в layout сайдбара, как удобнее):
   - Тумблер «Напоминать о невыполненных привычках» — переключает `reminderEnabled`.
   - Поле времени — простой `<input type="time">`, стилизованный под вид из макета (можно скрыть нативный вид инпута и оформить обёртку в стиле макета), привязан к `reminderTime`.
   - Блок с разрешением — три состояния в зависимости от `permissionStatus`:
     - `default` — плашка на `--coral-soft` с текстом и кнопкой «Разрешить» (как в макете);
     - `granted` — короткая строка со статусом (иконка галочки + «Уведомления разрешены»), кнопки нет;
     - `denied` — текст с инструкцией «Уведомления заблокированы в настройках браузера — включите их вручную», без кнопки (повторный вызов `requestPermission()` при `denied` не покажет системный диалог).
   - Внизу попапа — мелкий текст «Работает, пока вкладка приложения открыта в браузере» (честно предупреждаем про ограничение localStorage-only приложения без бэкенда).

Тумблер и выбор времени должны быть доступны и до выдачи разрешения браузером — пользователь может всё настроить заранее.
